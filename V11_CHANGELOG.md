# V11 CHANGES

- Laporan tidak lagi terbatas pada 120 nomor.
- Template memakai blok daftar hadir pertama sebagai tabel utama.
- Blok daftar hadir lama setelah blok pertama tidak ikut tercetak, sehingga tanda tangan pertama tetap berada setelah daftar.
- Baris peserta ditambahkan otomatis sebanyak jumlah kehadiran.
- Nomor memakai `display_order` dari backend.
- Kop/header, metadata kegiatan, dan tanda tangan dipertahankan.
